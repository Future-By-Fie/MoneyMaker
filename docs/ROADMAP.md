## Later — Flex
- [ ] Original MoneyMaker sound identity
- [ ] Optional celebration for goal achievement
- [ ] Prototype regional charts and voting
- [ ] Investigate music-provider partnerships and ringtone rights

## Conditional — Financial automation
- [ ] Evaluate regulated Open Banking providers
- [ ] Review GDPR, data retention and security architecture
- [ ] Add optional bank connectivity only if validated as useful

## Go / No-Go experiment

Invite 10 target users to use a lightweight prototype for 7 days.

Track onboarding completion, goal creation, voluntary Money Checks, return visits and perceived trust. Decide on next iteration based on actual behavior, not enthusiasm alone.

**No public release is implied by this roadmap.**
